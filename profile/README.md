# Monster Gaming

**AI-powered game development platform.**

Monster Gaming is an AI platform that sits above the engine. We route your queries through 145+ specialist agents — shader, animation, netcode, level design, QA, and more — purpose-built for [Unreal Engine](https://monstergaming.ai), Unity, Godot, and bespoke engines.

## What We Build

- **[Monster-GPT](https://monstergaming.ai)** — flagship model that auto-routes to specialist agents across 30+ game dev disciplines
- **[OpenAI-compatible API](https://monstergaming.ai/quickstart)** — drop-in replacement for OpenAI SDKs with game-dev-tuned models
- **[Engine-aware code generation](https://monstergaming.ai)** — writes gameplay systems, shaders, networking, and UI that actually compile
- **[Loki Code](https://blog.monstergaming.ai/we-built-our-own-ai-coding-cli-in-c-because-ours-got-revoked/)** — our open-source AI coding CLI, built in C11, 195 tests, 8.1 MB
